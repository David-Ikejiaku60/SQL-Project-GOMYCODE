# SQL Business Query Project

This project is a collection of SQL queries completed as part of the GoMyCode Data Science Bootcamp. The objective was to analyze a sales database by solving real-world business questions using Microsoft SQL Server.

## Project Overview

The project consists of:

- Creating and using a relational database
- Writing business-oriented SQL queries
- Working with multiple related tables
- Applying filtering, aggregation, joins, subqueries, window functions, and Common Table Expressions (CTEs)

The queries answer common business questions such as customer behavior, supplier analysis, product filtering, employee analysis, and sales reporting.

## Database Tables

The database contains the following tables:

- Customers
- Employees
- Orders
- Order_Details
- Products
- Categories
- Suppliers

These tables are related using Primary Keys and Foreign Keys to form a normalized relational database.

## SQL Concepts Demonstrated

This project demonstrates the use of:

- SELECT statements

- Aggregate Functions (COUNT, SUM)
- CASE expressions

- Common Table Expressions (CTEs)
- Window Functions (ROW_NUMBER)

## Business Questions Solved

Examples include:

- Display employees whose net salary exceeds a given threshold.
- Find suppliers of beverage products.
- Identify customers from a specific region.
- Calculate new discount rates based on total order value.
- Find customers who ordered all available products.
- Count orders placed by customers in France.
- Compare yearly order counts.
- Filter products based on multiple business rules.
